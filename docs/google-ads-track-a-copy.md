# Track A — Ad Copy & Keyword Pack (Education Funnel)

**Companion to:** `docs/google-ads-guide.md`
**Strategy:** advertise the *tool/information*, never a loan offer. All copy
points to educational landing pages with no loan-application solicitation.

**Google limits respected here:** Responsive Search Ad = up to **15 headlines
(≤30 chars)** + **4 descriptions (≤90 chars)**. Display path = 2 fields
(≤15 chars each). Char counts are shown in `()` after each headline.

**Match-type notation:** `"phrase"` = phrase match · `[exact]` = exact match.
Start with phrase + exact only (no broad) and expand from the search-terms
report. Pin the tool-name headline (★) to Position 1 in each ad group.

## Launch notes
- **Match types:** start phrase + exact; no broad until you have conversion data.
- **Pin** the ★ headline to Position 1 so the tool name always shows.
- **Conversions to track** (see guide §6): `calculate_emi`, `check_eligibility`,
  `tool_engaged`, `nav_to_homepage_form`, and the `/thank-you` lead submit.
- **Compliance red lines:** never write "get a loan", "instant approval",
  "guaranteed", a specific APR/amount promise, or use another lender's brand.
- Replace `yourdomain.in` in the Final URLs with your live domain.
